## Brand & Style

The design system establishes a high-performance, command-center aesthetic tailored for power users, digital creators, and administrators managing high-volume portfolio nodes. The visual tone balances technical authority with bleeding-edge digital elegance—evoking precision, speed, and absolute operational control.

The style converges **Dark Minimalist Precision** with **Cyber Glassmorphism**:
- Ultra-deep obsidian surfaces eliminate eye fatigue during sustained administrative sessions while allowing vital data metrics to stand out with deliberate luminance.
- Crimson red accents serve as the authoritative brand engine, delivering focal energy to primary interactions and core analytics.
- Electric cyan highlights and emerald telemetry badges provide hyper-contrast data indicators, injecting a technical pulse into high-density dashboard layouts.
- Tactile glassmorphism is utilized conservatively: translucent containers, subtle multi-stop 1px border glows, and crisp structural delineations keep content hierarchy legibly partitioned without decorative noise.

## Colors

The palette operates across strict tonal tiers engineered for dark-mode depth and optical hierarchy:

- **Primary Engine (Crimson)**:
  - Base Primary: `#e11d48` (Primary buttons, key focus states, active navigation accents)
  - Hover / Luminescence: `#ff2d55` (Hover actions, active glow radiuses, alert triggers)
  - Deep Crimson: `#be123c` and `#9f1239` (Pressed states, tonal container fills, soft gradient stops)

- **Secondary Engine (Cyber Cyan)**:
  - Base Cyan: `#06b6d4` (Informational metrics, link elements, secondary interactive nodes)
  - Neon Highlight: `#00f5ff` (Micro-glows, selected metric graphs, active filter markers)

- **Tertiary & Functional (Status Engine)**:
  - Success / Live: `#10b981` (Published states, positive delta metrics, active server nodes)
  - Warning: `#f59e0b` (Pending approval, draft warnings)
  - Danger / Destructive: `#f43f5e` (Terminal destructive operations, critical errors)

- **Neutral Foundations (Obsidian Canvas)**:
  - Base Void (Canvas Background): `#0a0a0f`
  - Layer 1 (Cards, Sidebars, Modals): `#12121a`
  - Layer 2 (Elevated Inputs, Headers, Menus): `#1a1a24`
  - Layer 3 (Hover Tiers, Border Foundations): `#262638`

- **Text & Foreground Metrics**:
  - High Contrast: `#f8fafc` (Headlines, prominent KPI numbers)
  - Medium Contrast: `#94a3b8` (Secondary body labels, field headers)
  - Low Contrast / Muted: `#64748b` (Disabled items, placeholders, table column heads)

## Typography

The typographic system orchestrates three distinct roles:
1. **Plus Jakarta Sans** leads structural hierarchy and high-level numeric readouts. Its geometric authority provides clarity across page titles, modular card headers, and large metric counters.
2. **Inter** handles high-volume admin content, long-form tables, dynamic form inputs, and system meta-information. It provides extreme legibility at small scale within dense data screens.
3. **Space Grotesk** is deployed deliberately as the technical accent. It powers status badges, code fragments, table pill identifiers, micro-tags, and system telemetry labels, providing an authentic terminal cadence.

All tabular numbers (`tnum`) must be enforced for metric tables, stat cards, and counters to prevent layout shift during real-time updates.

## Layout & Spacing

The layout is anchored on an 8pt architectural grid with a fluid administrative workspace model:

- **Navigation Shell**: Fixed persistent sidebar (260px desktop width, collapsible to 72px icon rail on tablet/compact views) combined with a pinned sticky top telemetry header (64px height).
- **Workspace Canvas**: A 12-column fluid grid system spanning the remaining viewport width, capped at 1600px maximum inner canvas to preserve readability across ultra-wide monitors.
- **Breakpoints**:
  - Desktop Large: `>= 1440px` (12 columns, 24px gutter, full multi-pane panels)
  - Desktop Standard: `1024px - 1439px` (12 columns, 20px gutter, auto-collapsible secondary tools)
  - Tablet: `768px - 1023px` (8 columns, 16px gutter, collapsed sidebar, single stacked side-drawers)
  - Mobile: `< 768px` (4 columns, 12px gutter, off-canvas navigation drawer, bottom sheets for forms)

Spacing between related field-level modules strictly uses `space-sm` (8px) and `space-md` (16px), whereas dashboard card clusters and major analytic regions decouple using `space-lg` (24px) and `space-xl` (40px).

## Elevation & Depth

Depth is conveyed through tonal surface layering, translucent glassmorphism, and colored edge luminescence rather than heavy drop shadows:

- **Level 0 (Canvas Void)**: Solid `#0a0a0f`. Unlit foundation.
- **Level 1 (Surface Containers & Content Cards)**:
  - Background: `rgba(18, 18, 26, 0.75)` with `backdrop-filter: blur(12px)`.
  - Border: 1px solid `rgba(255, 255, 255, 0.07)`.
  - Elevation Accent: Top 1px subtle highlight of `rgba(255, 255, 255, 0.12)` providing ambient ceiling light reflection.
- **Level 2 (Dropdowns, Floating Toolbars, Active Rows)**:
  - Background: `rgba(26, 26, 36, 0.90)` with `backdrop-filter: blur(16px)`.
  - Border: 1px solid `rgba(255, 255, 255, 0.14)`.
  - Shadow: `0 12px 32px -4px rgba(0, 0, 0, 0.6)`.
- **Level 3 (Modals, Command Palettes, Critical Drawers)**:
  - Background: `#161622`.
  - Border: 1px solid `rgba(225, 29, 72, 0.35)` with an ambient multi-stop shadow: `0 24px 48px -12px rgba(0, 0, 0, 0.85), 0 0 32px 0 rgba(225, 29, 72, 0.08)`.
- **Interactive State Glows**:
  - Focus and hover on high-priority elements trigger directional edge illumination using a 1px pseudo-border gradient: `#e11d48` transitioning to `#06b6d4`.

## Shapes

The geometric framework is strictly controlled at **Soft (Level 1)** to maintain an assertive, architectural tech discipline. Rounded corners are never overly bubbly; they provide subtle optical softness while retaining sharp structural division:

- **Standard Inputs, Buttons, & Table Cells**: `0.25rem` (4px).
- **Cards, Panels, & Modal Dialogue Windows**: `0.5rem` (8px).
- **Nested Inner Containers**: `0.25rem` (4px) to preserve mathematical harmony with host containers.
- **Status Badges, Indicators, and Filter Pills**: Pill radius (`9999px`) to create instant silhouette contrast against strictly rectangular data modules.

## Components

### Buttons
- **Primary Action**: Solid `#e11d48` background with `#ffffff` text, 0.25rem corner radius. Hover shifts to `#ff2d55` with a subtle localized aura (`0 0 16px rgba(225, 29, 72, 0.45)`). Active state compresses to `#be123c`.
- **Secondary Action**: Bordered ghost button. Background `rgba(26, 26, 36, 0.6)`, 1px border `rgba(255, 255, 255, 0.15)`, text `#f8fafc`. Hover transitions border to `#06b6d4` with matching text color.
- **Destructive**: Tonal deep red background `rgba(159, 18, 57, 0.2)` with 1px border `rgba(225, 29, 72, 0.4)`, text `#ff2d55`. Hover elevates background to `#e11d48` with pure white text.

### Stat Counters & KPI Cards
- Encased in Level 1 glass containers. Features an upper eyebrow label in `label-sm` (Space Grotesk, muted `#64748b`), a large numeric readout using `stat-counter` (Plus Jakarta Sans, `#f8fafc`), and a bottom telemetry delta. Positive delta indicators use `#10b981` paired with micro-arrow glyphs; negative trends display `#f43f5e`.

### Status Badges & Pills
- Rendered with `badge-tech` typography (Space Grotesk, 11px uppercase).
- **Live / Active**: Pill container with `rgba(16, 185, 129, 0.12)` fill, 1px border `rgba(16, 185, 129, 0.3)`, text `#10b981`, preceded by a 6px glowing green status orb.
- **Processing / Syncing**: Cyan container `rgba(6, 182, 212, 0.12)`, border `rgba(6, 182, 212, 0.3)`, text `#00f5ff`.
- **Draft / Inactive**: Neutral container `rgba(255, 255, 255, 0.05)`, border `rgba(255, 255, 255, 0.1)`, text `#94a3b8`.

### Data Tables
- Header: Sticky `#12121a` surface, text in `label-sm` uppercase `#64748b`, separated by a crisp 1px divider `rgba(255, 255, 255, 0.08)`.
- Rows: Transparent backgrounds with 1px bottom border `rgba(255, 255, 255, 0.04)`. Hover state triggers full-row background transition to `rgba(26, 26, 36, 0.7)` and exposes a 2px left border accent in `#e11d48`.
- Cell Alignment: Numbers right-aligned with fixed widths; text left-aligned with truncation rules.

### Input Fields & Controls
- Base background `#12121a` with 1px border `rgba(255, 255, 255, 0.12)` and inner inset shadow.
- Focused state: 1px border `#06b6d4`, accompanied by a subtle outer cyan illumination ring (`0 0 0 2px rgba(6, 182, 212, 0.2)`).
- Checkboxes: 16x16px boxes with 2px radius. Active state filled with `#e11d48` containing a white geometric checkmark.

### Sidebar Navigation
- Vertical structural rail with `#0a0a0f` foundation and 1px right border `rgba(255, 255, 255, 0.06)`.
- Navigation items: Standard state text `#94a3b8` with transparent left indicator. Active state displays crimson glow text `#ffffff`, background `rgba(225, 29, 72, 0.08)`, and a persistent 3px vertical `#e11d48` leading edge indicator.

### Modals & Drawers
- Dimmed obsidian overlay (`rgba(10, 10, 15, 0.8)` with `backdrop-filter: blur(8px)`). Modal shell features Level 3 elevation with subtle top-gradient highlight in crimson to maintain brand signature.
